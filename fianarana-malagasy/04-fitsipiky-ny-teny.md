# Niveau 4 — ny fitsipiky ny teny (la grammaire)

Matériel de travail : le PE T5, p.19, qui énumère les notions de la branche `Fitsipiky ny teny`. Chaque
point ci-dessous porte la note du PE quand il en a un ; sinon il est marqué `tsy mbola voamarina` et je ne
m'en sers pas pour corriger autrui.

## 1. Ny tsirinteny (les infixes, ce qui entre dans le verbe)

Le PE les donne tels quels : **`-in-`**, **`-if-`**, **`-amp-`**.

| tsirinteny | dikan-teny | ohatra |
|---|---|---|
| `-in-` | point de vue sur ce qui subit / sur le lieu | `sintaka` ↔ diso : à confirmer dans un texte |
| `-if-` | ce qui se fait entre eux (réciproque) | `mifandray`, `miarahaba` |
| `-amp-` | faire faire (causatif) | `ampianatra` (faire apprendre = enseigner), `ampitaina` |

**Terme à ne plus jamais employer faux** : `tsofoka` n'est pas la « citation » ni les guillemets ; le PE dit
`tsirinteny tsofoka amin'ny matoanteny : -in-, -if-, -amp-`. `farango sosona`, lui, vaut « … ».

## 2. Ny endriky ny matoanteny (les voix)

| endrika | ataon'ainy | modely |
|---|---|---|
| `mi-` / `man-` | le sujet fait (agent) | `mamaky boky`, `manasa ny tanany` |
| `-a` / `-ina` | ce sur quoi tombe l'action (patient) | `voriana`, `nasana ny tanana` — **tsy mbola voamarina** |
| `ma-` | état résultant | `mafana`, `madio` |
| `mifan-` / `-if-` | l'un l'autre | `mifampianatra` |

`mifamp-` et `ifamp-` : la racine est `mifan-` ; j'écris ce que le texte lu porte (`mifampianatra`
vs `ifampianatra` = deux choses, à ne pas mélanger).

## 3. Ny mpisolo tena (les pronoms) — deux séries, pas une

Le PE (p.19) pose le `mpisolo tena tampisaka` en deux colonnes :

| | endrika feno | tsy manana endrika feno |
|---|---|---|
| 1re pers. sg. | `-ko` | `-o` |
| 2e pers. sg. | `-nao` | `-ao` |
| 3e pers. sg. | `-ny` | (pas de courte) |
| 1re pl. inclus./exclus. | `-ntsika` / `-nay` | `-tsika` / `-nay` |
| 2e pl. | `-nareo` | `-areo` |

C'est `an-tampony` ou `anany` ? — `any`/`ao`/`eto`/`any an-tany` : les adverbes de lieu ne se déduisent
pas, ils s'apprennent par le texte. État : **tsy mbola voamarina**, à relever dans un `Vakiteny` avant d'en
faire une règle.

## 4. Ny filazana (déclaratif, interrogatif, impératif)

- mandidy (impératif) : **mirary** = tavana `-a` + tendro (`tsarà`, `salamà`, `mahavità`) ;
  **mandrara** = `aza` + verbe `mi-`.
- `V.A.` dans une grille : jamais vide, une ligne = une réponse.
- une consigne = un verbe d'action à l'impératif. Les sept que j'emploie sont ceux que j'ai lus dans les
  manuels : `Jereo` (regarde), `Veroso` (place), `Ampiasao` (utilise), `Avereno` (reprends), `Fenoy`
  (remplis), `Safio` (choisis), `Laharo` (écris). Un huitième, `Zarao`, n'a encore été lu nulle part sous
  cette forme : **il reste interdit** tant que le corpus ne me l'a pas montré.
