## Formats relevés dans les documents fournis

### Épreuve OPERATION

Les documents ne présentent pas vingt fois la même liste d’opérations. On trouve notamment :

1. écrire des nombres en lettres ;
2. écrire des nombres en chiffres ;
3. calculer le périmètre d’un rectangle à partir d’un schéma ;
4. convertir puis effectuer une opération : `7 dm − 31 cm` ;
5. effectuer une addition ou une multiplication ;
6. ranger des nombres dans l’ordre croissant ;
7. compléter un terme manquant ;
8. comparer des nombres décimaux : `10,1 … 10,099` ;
9. reconnaître les zéros inutiles : `37,2 = 37,200` ;
10. comparer des capacités ou des longueurs : `39 L … 900 mL`, `7 hm … 700 m` ;
11. convertir des masses : `300 kg = … t`, `9,2 q = … hg` ;
12. calculer l’aire d’une figure avec la formule ;
13. tracer deux droites perpendiculaires ;
14. écrire la fraction correspondant à une situation ;
15. résoudre une situation multiplicative simple : plusieurs vaches, une quantité par vache, une production totale.

### Épreuve PROBLEME

Le problème n’est pas une seule opération isolée. Il enchaîne plusieurs sous-questions dans une même situation :

- terrain rectangulaire : périmètre ;
- achat du terrain : reste de la somme ;
- sacs d’engrais : masse totale ;
- perte de sacs : nombre restant ;
- masse perdue ;
- achat de plusieurs produits à des prix unitaires différents ;
- prix total ;
- frais de transport ;
- prix de revient.

Le corrigé fourni dans les documents emploie explicitement le tableau :

| Solution | Résultat | Opération | Barème |
|---|---|---|---|
| étapes du calcul | réponse avec unité | calcul posé | points |

Le manuel T5 reprend maintenant ce principe sous la forme `Solution | Résultat | Opération`. Le barème reste réservé aux sujets d’examen où il est utile.

## Décisions de révision

- Ne plus générer une série où seuls les nombres changent.
- Faire varier la consigne, le type de compétence, l’ordre des exercices et la situation malgache.
- Maintenir les tableaux de réponse pour les problèmes à plusieurs étapes.
- Montrer la formule avant le calcul pour périmètre et aire.
- Garder une réponse courte : données → opération → résultat avec unité.
- Retirer les pages graphiques génériques « MON CAHIER » : elles ressemblaient à un habillage automatique et répétaient le contenu. La règle, un exemple court et les exercices restent directement dans la leçon.
