# Conversations

Ce dossier conserve la trace des échanges utiles (questions / réponses / décisions) liés au projet **J-Learn**.

L'objectif : ne rien perdre, pouvoir relire plus tard, et partager facilement un sujet avec une autre personne
(enseignant, technicien, ami…), sans dépendre d'un fil de discussion privé.

## Règles simples

1. **Un sujet = un fichier.** Nom au format `AAAA-MM-JJ-sujet-court.md` (ex. `2026-10-29-debloquer-telephone-code-acces.md`).
2. **Toujours la même structure** (voir le gabarit plus bas) : récit, analyse, solution, sources.
3. **Français simple**, phrases courtes : ces notes doivent rester lisibles par tout le monde.
4. **Aucune donnée sensible** : pas de mot de passe, pas de code PIN réel, pas de numéro de téléphone complet,
   pas de capture d'écran contenant un compte. On décrit, on ne recopie pas.
5. **Indiquer la fiabilité** quand une information n'est pas certaine (`certain` / `probable` / `à vérifier`).

## Gabarit d'une nouvelle conversation

```markdown
# Titre court et clair

> **Date** : AAAA-MM-JJ
> **Participants** : …
> **Sujet** : …
> **Statut** : ouvert / résolu / en attente d'info

## 1. Le récit
## 2. Analyse (ce qui s'est réellement passé)
## 3. Ce qu'il faut faire, dans l'ordre
## 4. Ce qu'il ne faut PAS faire
## 5. Prévention
## 6. Sources
```
