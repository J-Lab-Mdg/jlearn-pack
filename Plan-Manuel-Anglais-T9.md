## Grammaire T9 (niveau avancé)
- U1 : I'd rather + inf, gerund (like/prefer), because, present continuous (temporary), simple past.
- U2 : reported speech (imperatives + past introductory verbs).
- U3 : exclamatory (what a / how), past continuous vs simple past, while/when, used to vs be used to, so/neither do I, contraste, structure du paragraphe.
- U4 : quantifiers, should, comparatives/superlatives, frequency adverbs, contraste/conséquence, be going to vs will, prépositions de temps.
- U5 : may/can (permission/possibilité/capacité), reported speech, must vs have to, don't have to ; youth problems, forbidding/warning/advice/opinions.
- U6 : comparatives/superlatives, relative pronouns, if clause type 2 ; agreement/disagreement ; traditional vs modern cures.
- U7 : word formation (jobs), present perfect vs simple past, since/for ; telephoning ; CV, job ad, application letter.
- U8 : if clauses types 2 et 3, verbs with gerund ; asking/giving directions ; pollution, climate change.
