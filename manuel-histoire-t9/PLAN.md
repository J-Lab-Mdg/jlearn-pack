## U2 — Le monde depuis 1914 (18 séances)
1. Les innovations scientifiques du XXe siècle (médecine, vaccins, ADN…)
2. Les innovations technologiques majeures (auto, aviation, radio-TV, informatique, Internet)
3. L'évolution des systèmes de production (taylorisme/fordisme, automatisation, mondialisation, délocalisation ; sociétés anonymes, concentration)
4. Les mutations socio-économiques (tertiarisation, féminisation, migrations, niveau de vie, société de consommation, chômage)
5. Les origines de la Première Guerre mondiale (tensions, Triple-Entente/Triple-Alliance, Sarajevo 28 juin 1914)
6. Le déroulement de la PGM : trois phases (mouvement 1914-15 ; position 1915-mars 1918 ; mouvement mars-nov 1918)
7. Les conséquences de la PGM (pertes, génocide arménien, traité de Versailles, nouvelles frontières)
8. L'effort de guerre à Madagascar (SICE, hausse des taxes, tirailleurs malgaches)
9. La révolution russe de 1917 et la naissance de l'URSS
10. La crise de 1929 et ses répercussions (dont Madagascar)
11. Les régimes totalitaires : le stalinisme (terreur, collectivisation, stakhanovisme)
12. Les régimes totalitaires : l'Italie fasciste et l'Allemagne nazie
13. La Seconde Guerre mondiale : causes et phases (Axe 1939-42, Alliés 1942-45)
14. Les conséquences de la SGM (pertes, Yalta/Potsdam, ONU, effort de guerre malgache)
15. Les relations internationales : définition ; de la SDN à l'ONU ; accords de paix (Paris 1947, Genève 1954, Moscou 1990)
16. La Guerre froide : origines, manifestations, apogée (1947-1962 : Berlin, Corée, Indochine, mur 1961)
17. La détente (1962-1991) : accords, limites (Cuba, Vietnam, Afghanistan), Gorbatchev, chute du mur 1989
18. Le monde depuis 1990 (fin URSS 1991, mondialisation, multipolarité, Yougoslavie, Rwanda, Moyen-Orient, terrorisme)
Docs envisagés : témoignage poilu Verdun ; lettre tirailleur malgache (reconstitué) ; 14 points de Wilson ou Versailles ; discours Staline/propagande ; Churchill rideau de fer 1946 ; JFK Berlin 1963 ; charte ONU 1945 ; Gorbatchev…

## U3 — La décolonisation (4 séances)
1. Les origines : facteurs externes (SGM, Brazzaville, ONU, USA-URSS) et internes (nationalisme, retour des tirailleurs)
2. Les acteurs et les étapes (Gandhi, Nehru, Boumediene, Senghor ; décolonisations anglaise, française, portugaise)
3. Les formes : pacifique (Inde, Madagascar) / violente (Algérie ; 29 mars 1947)
4. L'émergence du Tiers-Monde (Bandung 1955, non-alignement 1956, Belgrade 1961)
Docs : discours Brazzaville 1944 (adapté) ; Gandhi ; communiqué final Bandung 1955 (adapté)…

## U4 — Madagascar sous les Républiques (4 séances)
1. La Première République (1959-1972) et le directoire militaire (1972-1975) — réalisations (université 1961, SOMALAC…), événements 1972
2. La Deuxième République (1975-1993) — malgachisation, nationalisations — et la transition 1991-1992
3. La Troisième République (1992-2011) : Zafy, Ratsirahonana, Ratsiraka, Ravalomanana ; crise 2002 ; transition 2009-2014
4. La Quatrième République (depuis 2011) : Rajaonarimampianina, Rajoelina, transition 2025 ; raisons de l'instabilité (référendum, plébiscite, crises) ; bilan socio-économique
Docs : discours/presse d'époque adaptés ou reconstitués ; constitution.

## U5 — Les commémorations et les célébrations des mémoires collectives (3 séances)
1. Lieux de mémoire et mémoires collectives : définitions, catégories (symboles, monuments, commémorations, paysages)
2. La transmission des mémoires ; les oublis de l'Histoire (esclaves, nationalistes, cultures) ; le devoir de mémoire
3. Les manifestations de commémoration : défilé, conférence-débat, dépôt de gerbes, exposition
Docs : Pierre Nora (adapté) ; témoignage descendant 1947 (reconstitué) ; programme officiel 26 juin (reconstitué).
