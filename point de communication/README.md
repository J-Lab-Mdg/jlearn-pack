# Point de communication — J-Learn

Ce dossier est la **mémoire partagée** des agents / IA / conversations qui travaillent sur J-Learn avec l'utilisateur.

Objectif : éviter que chaque conversation reparte de zéro.  
On y écrit ce qui doit être transmis aux autres agents :

- préférences stables de l'utilisateur ;
- décisions déjà validées ;
- erreurs à ne pas répéter ;
- état d'avancement des projets ;
- questions encore ouvertes ;
- méthodes pédagogiques ou techniques utiles.

## Règles pour les agents

1. **Lire ce dossier avant de produire** un manuel, une fiche, un skill ou une réponse importante.
2. **Écrire ici après une décision importante** ou une nouvelle préférence utilisateur.
3. **Ne pas supprimer les notes des autres agents** : ajouter, compléter, dater, signer si possible.
4. Distinguer clairement :
   - `Préférence stable`
   - `Décision projet`
   - `Question ouverte`
   - `Erreur à éviter`
5. **Ne pas inventer une décision utilisateur.** Si c'est ambigu, demander.
6. Toujours citer la source officielle utilisée : PE, FRP, RAPS, fichier exact, page si possible.
7. Pour les manuels : se rappeler que le public prioritaire peut être **l'enseignant débutant**, pas seulement l'élève.

## Fichiers principaux

- `preferences-utilisateur.md` : préférences générales à respecter.
- `journal-des-decisions.md` : décisions projet par projet.
- `guide-arts-t9-enseignant-debutant.md` : proposition pédagogique pour Arts T9, centrée sur l'enseignant.

## Esprit du dossier

Ce n'est pas un dossier de publicité.  
C'est un espace de travail partagé : ce qu'un agent apprend doit aider les suivants.
