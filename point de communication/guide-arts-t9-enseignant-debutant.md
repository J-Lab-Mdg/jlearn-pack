# Guide Arts T9 — penser d'abord à l'enseignant débutant

Ce fichier propose une méthode pour transformer le manuel Arts T9 en outil réellement utilisable par un enseignant qui découvre la discipline.

## Idée centrale

Le manuel ne doit pas seulement dire :

> « L'élève dessine un objet. »

Il doit aider l'enseignant à savoir :

> « Qu'est-ce que je dis ? Qu'est-ce que je montre ? Qu'est-ce que je fais faire ? Comment je sais si l'élève a réussi ? »

## Structure proposée pour chaque séance

### A. Guide enseignant

1. **Ce que l'enseignant doit comprendre**
   - objectif réel de la séance ;
   - lien avec le PE ;
   - ce qui est important ;
   - ce qui n'est pas grave si c'est imparfait.

2. **Ce qu'il faut préparer**
   - objets ;
   - images ;
   - outils ;
   - espace ;
   - groupes ;
   - sécurité si nécessaire.

3. **Déroulement pas à pas**
   Pour chaque étape :
   - durée indicative ;
   - action de l'enseignant ;
   - phrase possible à dire ;
   - action des élèves ;
   - point de vigilance.

4. **Erreurs fréquentes**
   - seulement les erreurs probables ;
   - quoi observer ;
   - comment aider sans faire à la place de l'élève.

5. **Évaluation / observation**
   - ce que l'élève doit produire ;
   - critères simples ;
   - pas de note chiffrée obligatoire dans la fiche ;
   - encourager la présentation et l'amélioration.

### B. Trace élève

Après le guide enseignant, prévoir un court résumé pour l'élève :

- ce qu'il a appris ;
- les mots utiles ;
- la consigne de production ;
- un exemple attendu ;
- une grille très simple si nécessaire.

La trace élève doit être courte. Elle ne remplace pas le guide enseignant.

### C. Ressources média

- image de scène scolaire ;
- audio de consigne ou d'exemple parlé ;
- lien vidéo tutoriel si utile ;
- QR code ou lien court si possible.

## Exemple de formulation attendue

Au lieu de :

> « Faire observer les nuances. »

Écrire :

> **Enseignant :** « Regardez ce gobelet. Aujourd'hui, nous allons le dessiner pour qu'il ait l'air rond, pas plat. Pour cela, nous allons utiliser trois gris : un gris clair, un gris moyen et un gris foncé. »
>
> **Enseignant montre :** le côté éclairé, le côté sombre, puis l'ombre portée.
>
> **Élèves :** observent, montrent du doigt la zone claire et la zone sombre, puis commencent un essai au crayon.

## Trois gabarits selon la démarche du PE

Le PE Arts T9 utilise trois démarches. Le manuel doit les rendre visibles.

### 1. Interprétation

Utilisé surtout pour :
- dessin d'objet ;
- chant ;
- danse ;
- reproduction d'un modèle.

Étapes :
1. se familiariser ;
2. mémoriser ;
3. répéter / pratiquer ;
4. tenir compte des pairs ;
5. ajuster.

### 2. Création / invention

Utilisé surtout pour :
- peinture paysage ;
- sculpture / instrument recyclé ;
- chorégraphie ;
- pièce de théâtre.

Étapes :
1. inspiration ;
2. élaboration ;
3. mise en perspective ;
4. communication / présentation.

### 3. Appréciation

Utilisé surtout pour :
- identifier des couleurs ;
- identifier des instruments ;
- identifier des moyens corporels ;
- commenter une production.

Étapes :
1. examiner ;
2. relier ressenti et vu ;
3. porter un jugement simple.

## Ce que l'utilisateur attend vraiment

Un manuel qui rassure l'enseignant.

Il doit pouvoir ouvrir la page et savoir :
- quoi faire ;
- quoi dire ;
- quoi montrer ;
- quoi attendre des élèves ;
- comment réagir si les élèves sont perdus.

Le manuel doit être riche, mais pas compliqué.
