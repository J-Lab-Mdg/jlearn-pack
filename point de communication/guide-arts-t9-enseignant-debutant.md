# Guide Arts T9 — penser d'abord à l'enseignant débutant

Ce fichier propose une méthode pour transformer le manuel Arts T9 en outil réellement utilisable par un enseignant qui découvre la discipline.

## Idée centrale

Le manuel ne doit pas seulement dire :

> « L'élève dessine un objet. »

Il doit aider l'enseignant à savoir :

> « Qu'est-ce que je dis ? Qu'est-ce que je montre ? Qu'est-ce que je fais faire ? Comment je sais si l'élève a réussi ? »

## Structure validée pour une séance d'arts visuels / dessin

L'utilisateur a corrigé le premier prototype : les blocs A-E ne doivent pas être dispersés après la fiche. Ils doivent être **dans la fiche de préparation**, jusqu'à l'évaluation, comme dans les autres matières.

Ordre attendu :

### 1. FICHE DE PRÉPARATION COMPLÈTE

Elle contient :

- méta-table : discipline, sous-discipline, thème, titre, objectif, documentation, matériel, classe, séance, durée ;
- **A. Ce que l'enseignant doit comprendre** ;
- **B. Ce qu'il faut préparer** ;
- **C. Déroulement de la leçon** dans le tableau à 6 colonnes :
  - Étapes et Durée ;
  - Enseignant ;
  - Apprenants ;
  - Technique et Stratégie ;
  - Support et Matériel ;
  - Observation ;
- **D. Erreurs fréquentes et aides immédiates**, seulement si utiles ;
- **E. Évaluation de la production**, avec critères simples, sans note chiffrée obligatoire dans la fiche.

La fiche doit être prête à l'emploi : consignes réelles, phrases clés, réponses attendues, production attendue.

### 2. LEÇON ILLUSTRÉE, APRÈS LA FICHE

Après la fiche, on explique le contenu et chaque étape.

Ordre demandé :

1. **Image de scène scolaire d'abord**.
2. Quelques phrases d'explication.
3. **Étape 1 — Observation de l'objet** :
   - image de l'objet ;
   - flèches montrant ce que les élèves doivent remarquer : forme, ouverture, lumière, partie claire, partie sombre, dégradé, ombre portée.
4. **Étape 2 — Les nuances** :
   - trois gris : clair, moyen, foncé ;
   - graphique / nuancier à remplir d'abord au crayon par les élèves.
5. **Étape 3 — Le dessin de l'objet** :
   - **a. L'esquisse** : expliquer, puis montrer chaque geste avec une image ;
   - **b. Le modelé / impression de volume** : expliquer que la feuille reste en 2D et que les valeurs donnent l'impression de 3D ; montrer chaque geste avec une image ;
   - **c. L'ombre portée et les finitions** ;
   - **d. Comparer, expliquer, ajuster**.

Chaque sous-étape importante doit avoir :
- une explication simple ;
- une phrase clé que l'enseignant peut dire ;
- une image montrant le geste ou le résultat intermédiaire.

### 3. PRATIQUE, À LA PLACE DE « EXERCICES »

Pour les arts visuels, le champ après la leçon doit s'appeler **PRATIQUE**, pas « Exercices » par défaut.

La pratique doit :
- donner un **autre objet à dessiner** que celui de la démonstration ;
- demander de transférer la méthode ;
- donner des critères de réussite ;
- proposer des **liens vidéo YouTube** de tutoriel, avec icône vidéo ;
- éventuellement garder une courte trace élève.

## Terminologie à utiliser

- **Esquisse** : construction légère, repères, proportions, avant l'ombrage.
- **Modelé** : passage progressif de valeurs claires à foncées pour donner l'impression de volume.
- **2D / 3D** : la feuille reste plate (2D) ; le modelé donne l'impression de volume (3D). Ne pas dire qu'on transforme réellement le dessin en objet 3D.
- **Ombre portée** : ombre projetée sur le support, côté opposé à la lumière.
- **Pratique** : tâche de production / transfert, pas exercice écrit par défaut.

## Exemple de formulation attendue

Au lieu de :

> « Faire observer les nuances. »

Écrire :

> **Phrase clé :** « Regardez d'où vient la lumière. Montrez le côté clair, le côté sombre, puis l'ombre portée sur la table. »
>
> **Enseignant montre :** l'objet réel, puis l'image annotée.
>
> **Élèves :** observent, montrent du doigt les zones, puis remplissent le nuancier.

## Trois gabarits selon la démarche du PE

Le PE Arts T9 utilise trois démarches. Le manuel doit les rendre visibles.

### 1. Interprétation

Utilisé surtout pour :
- dessin d'objet ;
- chant ;
- danse ;
- reproduction d'un modèle.

Étapes :
1. se familiariser ;
2. mémoriser ;
3. répéter / pratiquer ;
4. tenir compte des pairs ;
5. ajuster.

### 2. Création / invention

Utilisé surtout pour :
- peinture paysage ;
- sculpture / instrument recyclé ;
- chorégraphie ;
- pièce de théâtre.

Étapes :
1. inspiration ;
2. élaboration ;
3. mise en perspective ;
4. communication / présentation.

### 3. Appréciation

Utilisé surtout pour :
- identifier des couleurs ;
- identifier des instruments ;
- identifier des moyens corporels ;
- commenter une production.

Étapes :
1. examiner ;
2. relier ressenti et vu ;
3. porter un jugement simple.

## Ce que l'utilisateur attend vraiment

Un manuel qui rassure l'enseignant.

Il doit pouvoir ouvrir la page et savoir :
- quoi faire ;
- quoi dire ;
- quoi montrer ;
- quoi attendre des élèves ;
- comment réagir si les élèves sont perdus.

Le manuel doit être riche, mais pas compliqué.
