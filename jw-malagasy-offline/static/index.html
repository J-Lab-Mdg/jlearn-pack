📱 Utiliser sur Android, iPhone & Disque Dur Externe (0 Mo Internet)

📶 Méthode 1 — Recherche & Téléchargement sans câble en Wi-Fi local (Android & iPhone)

Connectez votre téléphone et cet ordinateur au même Wi-Fi (ou au partage de connexion du téléphone, même sans forfait Internet actif), puis ouvrez cette adresse dans Chrome (Android) ou Safari (iPhone) :

Depuis votre téléphone, vous pourrez rechercher instantanément dans tous les chapitres malgaches stockés sur le disque dur externe ET toucher le bouton 📲 JWPUB d'un livre pour l'ouvrir directement dans JW Library !

🤖 Sur Android (100 % autonome dehors)

  1. Dans le dossier jw-malagasy-offline/fichiers/JWPUB/, vos fichiers .jwpub sont rangés proprement par catégorie.
  2. Copiez-les sur le téléphone (câble USB ou clé USB-C) : touchez un fichier .jwpub dans l'appli Fichiers → choisissez JW Library.
  3. Bonus moteur de recherche sur Android sans PC : installez Termux une fois, copiez le dossier et tapez bash lancer.sh puis ouvrez http://127.0.0.1:8767 dans Chrome !

🍏 Sur iPhone / iPad (iOS)

  1. En Wi-Fi local via l'adresse ci-dessus dans Safari : touchez 📲 JWPUB sur une publication → Télécharger → touchez le fichier → Partager → JW Library.
  2. Ou par câble USB / AirDrop / clé Lightning-USB-C : copiez les fichiers .jwpub ou .epub dans l'app Fichiers de l'iPhone → touchez un .jwpub → JW Library (ou Livres d'Apple pour les .epub).
💾 Règle d'or pour votre Disque Dur Externe : Avant de débrancher le câble USB de votre disque dur externe, fermez toujours la fenêtre noire du serveur (ou cliquez sur Arrêter proprement si un téléchargement est en cours) afin que la base SQLite enregistre proprement toutes les données.
