Chiffres au dernier pointage : **75 séances, 67 images, ~104 000 mots, 2,95 Mo.**

Règle du 2026-09-11 : **chaque leçon ouvre sur une image.** Sujet concret
(lever du soleil, école, village, quartier, ville) -> **scène générée** ; sujet
abstrait (croix des points cardinaux, rose des vents, plan, échelle) -> schéma
ImageMagick. Table `ILLUSTRATIONS` dans `generer_t1.py`. Contrôle automatisé :
27 leçons sur 27 ouvrent sur une image.

Correctif important du 2026-09-11 : les figures sortaient en **PNG 16 bits** (défaut
ImageMagick) et Word refusait d'ouvrir le fichier. `Fig.save()` force désormais
`-depth 8` + `png24:`. Le T1 est passé de 2,6 Mo à 1,15 Mo.

## Comment produire la suite

```bash
cd geographie-9e
# 1. ajouter les séances suivantes dans contenu_t1.py (SEANCES.append(dict(...)))
# 2. ajouter au besoin les figures dans tools/figures.py (dict FIGURES_T1 / FIGURES_T1B)
# 3. régénérer tout le trimestre d'un coup :
python3 generer_t1.py
```

Contrôles automatiques à chaque génération : `sectPr` = 1 · `ns0:` = 0 · 32 namespaces ·
0 double espace · tous les XML bien formés · Times New Roman partout.

## Contraintes techniques de cet environnement

- **Pas de réseau** → `npm install docx` impossible : le corps du document est écrit en OOXML
  directement (`tools/jlearn_docx.py`), à partir du squelette
  `Manuel_Geographie_1ereACD_V1_FINAL.docx` (32 namespaces, `sectPr` unique, styles).
- **Pas de rasteriseur SVG** (ni rsvg, ni cairosvg, ni sharp, ni PIL) → les figures
  géométriques sont dessinées avec **ImageMagick** (`tools/figures.py`, police DejaVu) ;
  les scènes non géométriques sont **générées à part** puis redimensionnées à 1100 px.
- **Pas de LibreOffice** → aucun rendu PDF de contrôle possible ici ; la vérification
  visuelle doit être faite par l'utilisateur dans Word.
