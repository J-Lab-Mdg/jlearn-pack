## Méthode

- Une page n'entre dans `sources.py` (et donc dans ce dossier) **que si elle a été ouverte** et si les paragraphes recopiés l'ont été depuis le texte obtenu : aucune citation n'est écrite de mémoire.
- Seuls les passages utilisés sont stockés, plus l'URL, la licence et l'attribution. Le texte intégral d'une page, quand il est utile, est déposé dans `full/<clé>.txt` puis ré-emballé par ce script.
- Pas de date de consultation dans le manuel : la référence complète et le permalien font foi.
