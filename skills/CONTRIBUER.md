# 🤝 Invitation à contribuer — pour toute discussion/session qui lit ce dossier

Ce dossier est un **document vivant**. Si tu es une session (IA ou humaine) qui
travaille sur un manuel J-Learn et que tu lis ces fichiers :

## Tu es invité(e) à mettre à jour ce dossier

Consigne ici ce que **toi** tu as appris de ton côté pendant ta tâche :
- une nouvelle préférence exprimée par J-Lab ;
- une correction terminologique ou pédagogique ;
- un piège technique rencontré (et sa solution) ;
- une amélioration de la chaîne de production ;
- un fait de contexte à connaître (PE mis à jour, actualité, etc.).

## ⚠️ Règle absolue : CONFIRMATION AVANT APPLICATION

Tout le monde peut apporter sa contribution, **mais** :

1. **Proposer d'abord** — présenter à J-Lab ce que tu comptes ajouter/modifier
   dans ce dossier, et pourquoi ;
2. **Attendre sa confirmation explicite** ;
3. **Seulement ensuite** : écrire, commiter, pousser.

De même dans l'autre sens : une préférence lue ici ne s'applique pas aveuglément
à ta tâche — utilise `QUESTIONS-AVANT-TACHE.md` pour faire confirmer les points
qui engagent ton livrable.

## Comment consigner ta contribution

1. Ajoute une entrée **en haut** de `JOURNAL-CONTRIBUTIONS.md` (format ci-dessous) ;
2. Si c'est une préférence durable confirmée → intègre-la aussi dans la bonne
   section de `PREFERENCES-JLEARN.md` ;
3. Si c'est une question de cadrage récurrente → ajoute-la à
   `QUESTIONS-AVANT-TACHE.md` ;
4. Ne modifie **jamais** `jlearn-manuel-scolaire-v18/` (archive intacte) : les
   évolutions du skill se proposent à J-Lab pour une future version.

### Format d'une entrée de journal

```markdown
## AAAA-MM-JJ — <tâche/manuel concerné>
- **Appris** : <ce qui a été découvert/décidé>
- **Statut** : confirmé par J-Lab le <date> / proposé, en attente
- **Fichiers impactés** : PREFERENCES-JLEARN.md §n / QUESTIONS-AVANT-TACHE.md / aucun
```
